# Easyplane

Site de démonstration autonome en HTML, CSS et JavaScript.

Ouvrir `easyplane.code-workspace` dans VS Code. Le code du site est dans `index.html` et les ressources locales dans `photos/`.

Pour afficher le site, ouvrir `index.html` dans un navigateur, ou lancer `python3 -m http.server 8000` dans ce dossier puis consulter http://localhost:8000.
